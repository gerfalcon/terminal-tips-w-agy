# Difficulty levels

The player picks a level: Easy, Normal or Hard. The level is in the address, for example `/?level=easy`.

- Easy: the first letter of every word is already filled in.
- Normal: the game as it is today. This is the default.
- Hard: the clues do not show the word length.
- The page shows the three levels as links, and marks the one in use.

Done when: the project check passes, there is a test for each level, and each level works in the browser.
