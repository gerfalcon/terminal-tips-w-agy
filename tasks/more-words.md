# More words

Add a second puzzle, "AI words", with at least 6 words about AI and coding agents,
for example AGENT, MODEL, TOKEN, CONTEXT. Write short, plain clues.

- The player can switch between the puzzles on the page. The address says which one, for example `/?puzzle=ai-1`.
- The puzzles stage of the check must pass: words cross on the same letter, ids match the numbers, clues are not empty.

Done when: the project check passes, and both puzzles can be solved in the browser.
